# Clasificación con Machine Learning y Redes Neuronales

## Descripción del proyecto

Repositorio dedicado a ejercicios de clasificación mediante técnicas de aprendizaje automático, con énfasis en la comprensión del flujo de entrenamiento, evaluación y comparación de modelos.

El trabajo permite estudiar cómo los algoritmos de clasificación utilizan variables de entrada para asignar observaciones a categorías y cómo se analiza su desempeño mediante métricas de evaluación.

## Objetivos

- Comprender los fundamentos de la clasificación supervisada.
- Preparar los datos para el entrenamiento de modelos.
- Explorar algoritmos de clasificación.
- Analizar el rendimiento de los modelos.
- Comprender el uso de métricas y herramientas de evaluación.
- Estudiar los fundamentos de las redes neuronales artificiales.

## Proyecto principal: clasificación multiclase con MLP

El proyecto descrito en el repositorio original utiliza el conjunto de datos Wine y el clasificador `MLPClassifier` de Scikit-learn.

El trabajo contempla:

- Entrenamiento de un modelo de perceptrón multicapa.
- Clasificación multiclase.
- Evaluación del desempeño.
- Análisis de la matriz de confusión y del reporte de clasificación.
- Comparación de algoritmos de clasificación.
- Validación cruzada de cinco pliegues.
- Exploración de arquitecturas y funciones de activación.

Los resultados numéricos y las configuraciones utilizadas deben consultarse en el notebook correspondiente.
